Privacy Policy

Last updated: September 15, 2026

AIditing (“the Software”) is a private, single-user tool that edits its owner's own interview footage and publishes it to its owner's own TikTok account. It is run locally by one individual (“the Operator”) on the Operator's own computer. It has no server, no user accounts, and no users other than the Operator. This policy explains what the Software processes and where that data lives.

1. Data the Software processes

  • TikTok OAuth credentials. An access token and a refresh token issued by TikTok for the Operator's own TikTok account, together with the basic account information TikTok returns when authorising (such as the open ID, display name and creator posting settings). These are used only to upload and publish videos to that same account.
  • Video files and related media. The raw interview footage the Operator records, intermediate files produced while editing (such as audio extracted for transcription and generated transcripts), and the final rendered video selected for publication.
  • Publication metadata. The caption, privacy setting and posting options the Operator chooses for a given video, and the status TikTok returns for that upload.

The Software collects no analytics, no tracking data, no advertising identifiers, and no information about visitors to this website.

2. Where data is stored

All of it is stored locally, on the Operator's own computer. OAuth tokens are kept in a local configuration file readable only by the Operator's user account; video files and transcripts are kept in local working folders. The Software does not operate a hosted backend and does not upload this data to any storage of its own. The only outbound transmission is to TikTok's API, and only for the purpose of publishing a video the Operator has explicitly approved.

3. No data from other people

The Software has a single user. It does not collect, request, receive or store personal data belonging to other users of TikTok or of any other service. It does not read other people's content, followers, messages or profiles. People who appear in the Operator's interview footage do so with their consent, as material the Operator has recorded and controls.

4. No sharing, no selling

No data processed by the Software is sold, rented, traded, shared with third parties, or used for advertising, profiling or any purpose beyond producing and publishing the Operator's own videos. The only third parties involved are the service providers strictly needed to do that work: TikTok, which receives the video and its caption in order to publish it to the Operator's account, and the speech-to-text provider used to transcribe the Operator's own footage, which receives only that audio and does not retain it for its own purposes.

5. Retention

  • OAuth tokens are kept only while the integration is in use. They are refreshed as TikTok requires and are deleted as soon as the Operator revokes access or stops using the Software; revoking AIditing from the TikTok account settings invalidates them immediately.
  • Intermediate files (extracted audio, transcripts, draft renders) are deleted once the corresponding video has been published or abandoned.
  • Source footage and published videos are kept locally by the Operator for as long as the Operator wishes, as personal media, and can be deleted at any time.

Because every file is local, deletion is immediate and complete: removing the file removes the data.

6. Security

Data stays on a personal computer protected by the Operator's operating system account and full-disk encryption. Communication with the TikTok API uses HTTPS. Tokens are never committed to source control and never shared.

7. Your rights

The only personal data involved is the Operator's own, held on the Operator's own machine, and can be inspected, exported or deleted directly at any time. If you believe the Software holds data concerning you — for example if you appear in footage — you may request access, correction or deletion using the contact address below.

8. Children

The Software is not directed at children and is not made available to anyone other than the Operator.

9. Changes to this policy
